# AI Mock Interview Coach

The complete project is located inside the **[mock-interview-ai/](mock-interview-ai/)** directory.

See:

➡️ **[mock-interview-ai/README.md](mock-interview-ai/README.md)**

This project implements a multi-agent AI Mock Interview Coach using:

- **LangGraph** (StateGraph multi-agent routing)
- **FastAPI** (REST Web API Backend)
- **Streamlit** (Interactive Frontend Dashboard)
- **Pydantic V2** (Structured data validation & schemas)
- **Python 3.12**
- **Groq API** (`llama-3.3-70b-versatile`) / **OpenAI** / **Gemini**
